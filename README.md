# Summer Heat Waves Mobile Alert System

This AI-powered tool helps predict potential heatwaves using real-time weather data and raises alerts to help citizens stay safe.

## Features
- Machine Learning prediction model (Random Forest)
- Inputs: Temperature, Humidity, Wind Speed
- Mobile-friendly UI using Streamlit
